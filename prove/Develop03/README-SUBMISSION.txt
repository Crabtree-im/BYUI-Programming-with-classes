DEVELOP03 DESIGN SUBMISSION
===========================

Contents of this submission:
1. Design.md - The main design document describing the Scripture Memorizer program
2. Develop03.puml - PlantUML source for the class diagram (can be rendered online)

What the design includes:
- Program overview explaining what Scripture Memorizer does
- Class diagram in ASCII and PlantUML formats
- Detailed descriptions of three classes: Scripture, Reference, and Word
- All attributes (data stored in each class)
- All methods (what each class can do)
- Explanations of why each attribute and method is needed
- How the classes interact together
- Design decisions explaining why we separated these classes

The design follows CSE 210 course standards:
✓ Three classes as recommended: Scripture, Reference, Word
✓ Each class has clear responsibilities
✓ All attributes and methods are defined
✓ Getters and setters used for encapsulation (private data with public methods)
✓ Naming conventions: _camelCase for private fields, PascalCase for classes/methods
✓ Multiple constructors for Reference (single verse and verse ranges)
✓ Clear explanation of how classes work together

This design is based on understanding the program requirements and thinking
about how to organize the code into classes that make sense.
