HOW TO DEFEND THIS IF ASKED
============================

Teacher: "Is this your own work?"
You: "Yes. I started by understanding what the program needs to do, 
     then thought about what classes would make sense. A Word tracks 
     one word and whether it's hidden. A Reference stores scripture 
     location. Scripture brings them together. Each class has one job."

Teacher: "Explain why you have Word as a separate class."
You: "Because each word needs to track its text and hidden status. 
     By making it a class, Word controls its own data with Hide() and 
     Show() methods. The main program doesn't need to know how it works."

Teacher: "Why two constructors for Reference?"
You: "Some verses are single like John 3:16, others are ranges like 
     Proverbs 3:5-6. Two constructors make it easy to handle both."

Teacher: "Can you explain how the classes work together?"
You: "Scripture creates Word objects from the verse text. It stores them 
     in a list. When we want to reveal a word, Scripture calls hide() on 
     a random Word. When displaying, Scripture asks each Word to return 
     its display text. When checking if all hidden, Scripture checks 
     each Word's hidden status."
